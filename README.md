# Adventure Lab Helper

A simple mobile-friendly app for tracking Adventure Lab clues, answers, notes, and geolocation.

## Features
- Add multiple stops or clues
- Save answers and notes per stop
- Track progress by answered stops
- Save the app state locally
- Use current location for each stop
- Copy the answer to the clipboard
- Works in browser mode and on mobile devices

## Run it locally

1. Install dependencies:
   npm install
2. Start the app:
   npx expo start
3. To open in a browser:
   npx expo start --web

## Notes
This app is intended to help you organize Adventure Lab clues and answer attempts. It does not automatically submit answers or interact with the actual Adventure Lab app itself.
